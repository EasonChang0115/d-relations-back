# D-Relations 目合わせ・力量テスト支援サイト（目視比對能力評估測驗平台）需求書

## 1. 專案概要

### 1.1 專案目的
本專案旨在開發一個針對醫療從業人員（特別是臨床檢查技師）的細胞識別能力評估平台。系統提供細胞圖像識別測驗，幫助使用者評估和提升其在末梢血和骨髓細胞識別方面的專業能力。

### 1.2 整體定位
- **目標用戶**：臨床檢查技師、醫師、學生及相關醫療從業人員
- **核心價值**：提供標準化的細胞識別能力評估工具
- **服務模式**：線上測驗平台，支援個人和團體使用

### 1.3 模組結構簡介
系統分為三個主要版本：

#### 1.3.1 免費版力量評價測驗（無料版力量評価チェック）
- 開放給所有使用者
- 15題測驗內容
- 基本結果報告
- 無需 OTP 認證

#### 1.3.2 個人付費版力量評價測驗（個人有料版力量評価チェック）
- 個人購買使用
- 20題測驗內容
- 詳細統計分析
- 含推薦課程資訊
- PDF 報告下載
- 需 OTP 認證

#### 1.3.3 團體配布版目合わせ評價測驗（有料版目合わせ評価チェック）
- 管理者購買並配布給團隊成員
- 統一測驗內容
- 團隊管理功能
- 集體結果分析
- 管理者和受測者皆需 OTP 認證

## 2. 使用者角色與權限

### 2.1 個人免費版受測者
**權限**：註冊個人資料、選擇測驗分野（末梢血版・骨髄版）、接受15題隨機測驗、查看基本測驗結果、無需身份認證
**限制**：每次測驗僅能進行一次、無法下載詳細報告、無統計分析功能

### 2.2 個人付費版受測者
**權限**：包含免費版所有功能、購買個人測驗、接受20題隨機測驗、查看詳細統計分析、查看推薦課程資訊、下載PDF測驗報告、10天受驗期限
**安全要求**：需通過OTP郵件認證、僅限本人使用

### 2.3 團體版配布者（管理者）
**權限**：購買團體測驗授權、設定受測者名單和郵件地址、查看所有受測者的測驗狀態、查看團體統計分析、下載個別受測者報告、管理畫面閱覽期限1個月
**管理功能**：配布測驗連結給受測者、監控受測進度、查看團體成績分析
**安全要求**：需通過OTP郵件認證、Session管理（1小時）

### 2.4 團體版受測者
**權限**：接收管理者分配的測驗連結、進行指定測驗（20題統一內容）、查看個人測驗結果、10天受驗期限
**限制**：無法查看他人成績、測驗內容由管理者統一決定
**安全要求**：需通過OTP郵件認證、Session管理

#### 3.1.2 頁尾（フッダー）

#### 3.1.3 使用者註冊功能（利用登録機能）
**輸入欄位**：
- 姓名（氏名）：文字輸入框
- 郵件地址（メールアドレス）：文字輸入框
- 組織代碼（組織コード）：文字輸入框（僅目合わせ評價測驗）
- 職種（職種）：複選選項 - 臨床檢查技師（臨床検査技師）/醫師（医師）/學生（学生）/其他（その他）
  - 特殊邏輯：選擇臨床檢查技師時顯示認定持有狀況選項、選擇其他時顯示文字輸入框
- 年代（年代）：單選選項 - 10代/20代/30代/40代/50代/60代以上
- 性別（性別）：單選選項 - 男性（男性）/女性（女性）/其他（その他）
- 居住地區（居住地域）：下拉選單 - 都道府県選擇

### 3.2 首頁模組（TOPページ）

**主要區域：**
- 第一視覺區（ファーストビュー）：主標題文字（見出しテキスト）、補充說明文字（補足テキスト）
- 引導文字區（リードテキスト）：主標題文字、補充說明文字、測驗示意圖（テストイメージ画像）

**三大測驗選項：**
1. **免費版力量評價測驗選擇欄**：主標題、補充說明、測驗示意圖、「開始測驗」按鈕（「テストをはじめる」ボタン）
2. **付費版力量評價測驗選擇欄**：主標題、補充說明、測驗示意圖、「開始測驗」按鈕
3. **付費版目合わせ評價測驗選擇欄**：主標題、補充說明、測驗示意圖、「開始測驗」按鈕

### 3.3 測驗相關頁面模組

#### 3.3.1 分類選擇畫面（カテゴリ選択画面）
**兩大分野選擇：**
- **末梢血版**：主標題文字（見出しテキスト）、補充說明文字、測驗示意圖、「開始測驗」按鈕
- **骨髓版**：主標題文字、補充說明文字、測驗示意圖、「開始測驗」按鈕

#### 3.3.2 測驗前說明頁面（テスト前のインストラクションページ）
**頁面要素：**
- 標題區域：主標題文字、補充說明文字
- 測驗回答步驟說明：主標題文字、補充說明文字、步驟說明文字（ステップ説明テキスト）
- 操作按鈕：「開始測驗」按鈕（「テストをはじめる」ボタン）、「回到首頁」按鈕（TOPへ戻るボタン）

### 3.4 測驗功能模組

#### 3.4.1 測驗隨機生成功能
**免費版規格**：15題、問題隨機、每個細胞10張圖片隨機顯示、大分類→細胞名稱下拉選單
**付費版規格**：20題、其他規格同免費版

**資料結構**：分野（末梢血版・骨髓版）→ 大分類 → 問題（細胞）→ 圖片 + 回答選擇項

#### 3.4.2 測驗進行功能
**回答規格**：一問一答形式、無回上一題功能、可跳過問題（視為錯誤）、可中途結束（無法重新開始）、回答後立即顯示正確答案和解說
**限制條件**：測驗開始後無法重複受驗、無中途儲存功能

#### 3.4.3 結果報告功能
**免費版報告**：測驗結果摘要（正答率/題目數/正解數/錯誤數）、回答一覽（細胞圖片/題目編號/回答結果）
**付費版額外功能**：統計資訊分析、推薦課程資訊（おすすめの講座情報）、PDF 報告下載功能

### 3.5 購買與管理功能模組

#### 3.5.1 Stripe 決済系統
**個人版**：測驗選擇 → 價格確認 → Stripe 付款 → 郵件通知
**團體版**：人數設定 → 價格計算 → Stripe 付款 → 管理者郵件通知

#### 3.5.2 OTP 認證系統
**認證流程**：連結點擊 → OTP 郵件發送 → 認證碼輸入 → 驗證成功 → Session 建立

#### 3.5.3 團體管理功能
**配布者設定**：受測者姓名和郵件地址輸入、測驗連結自動發送、受測者名單管理
**管理後台**：受測者測驗狀態一覽、受測日期時間、個人正答率、團體整體正答率、個別回答報告連結

## 4. 系統流程說明

### 4.1 個人版（免費／付費）

#### 4.1.1 免費版流程
```
使用者進入首頁
↓
選擇免費版力量評價測驗
↓
填寫個人資料註冊
↓
選擇測驗分野（末梢血版・骨髓版）
↓
閱讀測驗說明
↓
開始測驗（15題）
↓
查看測驗結果
```

**特點：**
- 無需 OTP 認證
- 任何人都可以受驗
- 基本結果報告

#### 4.1.2 個人付費版詳細流程

**步驟 1-2：購買階段**
```
1. 使用者購買測驗
↓
2. 📧 系統發送受驗連結郵件
   URL範例：https://example.com/test/exam/{access_token}
```

**步驟 3-10：認證階段**
```
3. 使用者點擊受驗連結
↓
4. 系統檢查狀態 → OTP 未認證
↓
5. 顯示 OTP 認證畫面
↓
6. 系統生成並發送 OTP
↓
7. 📧 發送 OTP 認證碼郵件
↓
8. 使用者輸入 OTP
↓
9. 系統驗證 OTP
↓
10. 認證成功
    - 記錄 otp_verified_at
    - 建立 Session
```

**步驟 11-14：測驗階段**
```
11. 顯示「測驗開始」畫面（「テストを始める」画面を表示）
↓
12. 使用者點擊「開始測驗」按鈕（[テストを始める]ボタンを押下）
↓
13. 系統記錄測驗開始
    - 記錄 test_started_at
↓
14. 顯示測驗畫面（第1題）
```

**重要特性：**
- 角色：購買者 = 受測者
- OTP 認證時機：受驗連結點擊時（每個裝置僅初次需要）
- 無管理畫面
- 受驗期限：10天

## 6. 特殊行為與例外處理

### 6.1 OTP 認證機制

#### 6.1.1 系統版本與認證方針

**系統版本概要：**
- **免費版**：任何人都可受驗，無 OTP 認證
- **個人付費版**：購買者本人受驗，需 OTP 認證
- **團體配布版**：購買者註冊受測者，各受測者需 OTP 認證，購買者有管理畫面

#### 6.1.2 認證目的
- **本人確認**：確認郵件地址所有者身份（本人確認: メールアドレスの所有者であることを確認）
- **防止冒名**：即使受驗連結外流，沒有郵件也無法受驗（なりすまし防止: 受験リンクが流出しても、メールがないと受験不可）
- **安全保障**：保護受測者姓名、測驗結果等個人資料（セキュリティ確保：受験者の氏名、受験結果は個人情報）
- **付費版價值保護**：即使受驗連結 URL・管理畫面 URL 外流，郵件地址所有者以外無法受驗（有料版の価値保護：受験リンクURL・管理画面URLが流出しても、メールアドレスの所有者以外は受験不可）

#### 6.1.3 各版本認證方針詳解

**免費版：**
- OTP 認證：無

**個人付費版：**
- 角色：購買者 = 受測者
- OTP 認證時機：受驗連結點擊時（每個裝置僅初次需要）
- 管理畫面：無

**團體配布版（購買者）：**
- 角色：購買者（配布者）
- OTP 認證時機：購買時（1回）、管理畫面存取時（跨裝置・瀏覽器時需重新認證）
- 管理畫面：有

**團體配布版（受測者）：**
- 角色：受測者
- OTP 認證時機：受驗連結點擊時（跨裝置・瀏覽器時需重新認證）
- 管理畫面：無

#### 6.1.4 認證時機判斷

**無需認證的情況：**
- 同一裝置 + 同一瀏覽器（同じデバイス + 同じブラウザ）
- Session 有效期限內（セッション有効期限内）
- Cookie 保持狀態（Cookieが保持されている）

**需要認證的情況：**
- 不同裝置（PC、手機、平板）（異なるデバイス（PC、スマホ、タブレット））
- 不同瀏覽器（Chrome、Firefox、Safari、Edge等）（異なるブラウザ（Chrome、Firefox、Safari、Edge等））
- 無痕模式・私人瀏覽（シークレットモード・プライベートブラウジング）
- Cookie 被刪除（Cookieを削除した場合）
- Session 有效期限過期（セッション有効期限切れ）

#### 6.1.5 Session 管理詳細規範

| 對象 | 基本Session | 延長規則 | 特殊條件 |
|------|-------------|----------|----------|
| 個人付費版（受測者） | 10天（受驗期間中） | 無延長 | 受驗期間內有效 |
| 團體版（購買者・管理畫面） | 1個月（閱覽期間） | 無延長 | 操作中也會過期 |
| 團體版（受測者） | 10天（受驗期間中） | 無延長 | 受驗期間內有效 |
| 測驗開始後 | 無需Session | - | 由資料庫狀態判斷 |

**重要 Session 管理規則：**

**測驗受測者的 Session 管理：**
- OTP 認證後到「開始測驗」按鈕按下為止，保持認證狀態
- 測驗開始後（「開始測驗」按鈕按下後）無法重複受驗，因此無需 Session，僅由資料庫狀態判斷

**測驗管理者的 Session 管理：**
- OTP 認證後建立 Session（1小時）
- 操作中超過1小時也會 Session 過期
- Session 過期後，存取管理畫面 URL 時需重新 OTP 認證

### 6.2 錯誤訊息處理

#### 6.2.1 OTP 認證相關錯誤

**OTP 代碼不符（HTTPステータス: 400）**
- 顯示訊息：「認證代碼不正確，請重新嘗試。（認証コードが正しくありません。もう一度お試しください。）」
- 附加元素：[重新發送認證代碼]連結（[認証コードを再送信する]リンク）

**OTP 有效期限過期（HTTPステータス: 400）**
- 顯示訊息：「認證代碼的有效期限（xx分）已過期。（認証コードの有効期限（xx分）が切れました。）」
- 附加元素：[重新發送認證代碼]連結（[認証コードを再送信する]リンク）

**OTP 重新發送速率限制（HTTPステータス: 429）**
- 顯示訊息：「認證嘗試次數已達上限，請稍後再試。（認証試行回数が上限に達しました。しばらく待ってから再試行してください。）」
- 附加元素：[重新發送認證代碼]連結（[認証コードを再送信する]リンク）

#### 6.2.2 Session 相關錯誤

**Session 無效（HTTPステータス: 401）**
- 顯示訊息：「需要進行認證。（認証が必要です。）」
- 附加元素：[進行認證]連結，跳轉至 OTP 認證畫面（[認証を行う]リンク（OTP認証画面へ遷移））

**Session 期限過期（HTTPステータス: 401）**
- 顯示訊息：「Session 有效期限已過期。（セッションの有効期限が切れました。）」
- 附加元素：[進行認證]連結，跳轉至 OTP 認證畫面（[認証を行う]リンク（OTP認証画面へ遷移））

#### 6.2.3 測驗受驗相關錯誤

**測驗已開始（HTTPステータス: 400）**
- 顯示訊息：「已經開始測驗，無法重新受驗。（すでにテストを開始しています。新たに受験することはできません。）」

**測驗已完成（HTTPステータス: 403）**
- 顯示訊息：「此測驗已受驗完畢，測驗僅能受驗一次。（このテストはすでに受験済みです。テストは一度しか受験できません。）」

**受驗期限過期（HTTPステータス: 403）**
- 顯示訊息：「受驗期限已過期。（受験期限が切れています。）」

**無法重新發送 OTP（HTTPステータス: 403）**
- 顯示訊息：「因測驗已開始，無法重新發送認證代碼。（テストを開始済みのため、認証コードを再送信できません。）」

#### 6.2.4 管理畫面相關錯誤

**找不到管理畫面（HTTPステータス: 404）**
- 顯示訊息：「找不到管理畫面，請確認 URL。（管理画面が見つかりません。URLをご確認ください。）」

**閱覽期限過期（HTTPステータス: 403）**
- 顯示訊息：「管理畫面的閱覽期限已過期。（管理画面の閲覧期限が切れています。）」

**購買時認證未完成（HTTPステータス: 403）**
- 顯示訊息：「購買時的本人確認尚未完成。（購入時の本人確認が完了していません。）」
- 附加元素：[進行認證]連結，跳轉至 OTP 認證畫面（[認証を行う]リンク（OTP認証画面へ遷移））

#### 6.2.5 連結・Token 相關錯誤

**受驗連結無效（HTTPステータス: 404）**
- 顯示訊息：「受驗連結無效，請確認 URL。（受験リンクが無効です。URLをご確認ください。）」

**管理畫面 Token 無效（HTTPステータス: 404）**
- 顯示訊息：「找不到管理畫面，請確認 URL。（管理画面が見つかりません。URLをご確認ください。）」

#### 6.2.6 系統錯誤

**伺服器錯誤（HTTPステータス: 500）**
- 顯示訊息：「發生伺服器錯誤，請稍後再試。（サーバーエラーが発生しました。しばらく待ってから再試行してください。）」

**服務無法使用（HTTPステータス: 503）**
- 顯示訊息：「目前無法使用服務。（現在サービスを利用できません。）」

## 7. 系統資料與隱私規範

### 7.1 個人資料保護

#### 7.1.1 收集的個人資料
**基本資料**：姓名（氏名）、郵件地址（メールアドレス）、職種資訊、年代、性別、居住地區
**測驗相關資料**：測驗結果、回答記錄、受驗時間、IP 地址（用於安全管控）

#### 7.1.2 資料使用目的
測驗服務提供、本人身份確認、統計分析（去識別化）、服務改善

#### 7.1.3 資料保護措施
資料加密儲存、存取權限控制、定期安全檢查、符合個人資料保護法規

### 7.2 Session 管理規範

#### 7.2.1 Session 有效期管理
| 使用者類型 | Session 期限 | 特殊條件 |
|------------|--------------|----------|
| 個人付費版受測者 | 10天 | 受驗期間內 |
| 團體版管理者 | 1小時 | 操作中也會過期 |
| 團體版受測者 | 10天 | 受驗期間內 |

#### 7.2.2 Session 失效條件
超過有效期限、使用者主動登出、系統偵測到異常行為、Cookie 被清除

### 7.3 資料保存期限

**個人資料保存**：測驗結果（購買後1年）、個人基本資料（服務使用期間）、Session資料（Session期限內）、Log記錄（6個月）
**系統資料保存**：OTP記錄（24小時）、測驗統計資料（永久保存/去識別化）、錯誤Log（3個月）、存取Log（1年）
**資料刪除機制**：保存期限到期自動刪除、使用者要求刪除、服務終止時的資料處理、定期清理無效資料

### 7.4 安全措施

**傳輸安全**：強制使用HTTPS、TLS 1.3加密、Certificate Pinning
**儲存安全**：資料庫加密、敏感資料Hash處理、定期備份
**存取控制**：最小權限原則、多重身份認證、API Rate Limiting、IP白名單機制

##團體配布版「管理者」流程：

管理者選擇購買人數 → 進入結帳頁面 → 結帳完成後，系統會寄出「管理畫面連結信」

管理者點擊信件中的連結時：
 • 若尚未驗證 → 會導向 OTP 認證頁面
 • 完成驗證後 → 導向「配布者設定」頁面

若驗證後尚未完成設定就關閉頁面，之後再次點擊連結：
 • 若 session 尚未過期（同一裝置、同一瀏覽器、1 小時內），可回到設定頁面繼續操作
 • 若 session 過期或變更裝置/瀏覽器，需重新進行 OTP 認證

設定完成後，會自動跳轉到「管理後台畫面」，並自動寄送測驗連結給受測者。

之後若再點擊該管理者信件中的連結，會直接進入管理畫面（因為配布者設定已完成）。
⸻
##團體配布版「受測者」流程：

受測者點擊測驗連結（有效期限為 10 天）時：
 • 若尚未認證 → 會跳轉至 OTP 認證頁面
 • 認證完成後 → 顯示「開始測驗」畫面

若受測者在答題過程中離開頁面，之後再回來：
 • 若 session 尚未過期 → 會導回他先前的作答進度
 • 若 session 過期或裝置改變 → 需重新認證，認證後一樣會導回進度

如果測驗已完成，再點擊連結會進入「測驗結果頁面」（有效期為 1 個月）
